## 📖 About This Repository

This repository is a community-driven academic knowledge base for CSE students of Rangpur Engineering College. Every course of the 4-year curriculum is organized into a dedicated folder so that students can find exactly what they need — without digging through scattered files.

---

## 🗂️ Repository Structure

Every course folder follows the same 4-category standard:

```text
📁 <Year>/<Semester>/<Course-Code-Title>/
    ├── 📁 Books/          # Textbooks & reference books
    ├── 📁 Notes/          # Class notes, slides & handouts
    ├── 📁 PYQ/            # Previous year questions & solutions
    └──  RU-Materials/   # Official RU/REC materials, suggestions & lab manuals
```

## 📝 File Naming Convention

To keep the archive searchable, files follow this format:

```text
[Year]-[CourseCode]-[Type]-[Description].[ext]
```

**Examples:**
- `2023-CSE1121-PYQ-Final.pdf`
- `2024-CSE2121-Notes-Linked-List.pdf`
- `CSE3121-Books-Fundamentals-of-Database-Systems.pdf`
